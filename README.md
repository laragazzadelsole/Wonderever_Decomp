# 🌅 Decompression Somewhere — Are You In?

A beautiful, interactive form to gather RSVPs and logistics for a decompression event in nature.

## 📋 Overview

This project is a single-page form designed to collect responses from festival-goers interested in attending a post-festival decompression gathering. It captures information about:

- Strike attendance
- Commitment level
- Duration availability
- Budget situation
- Transport & shelter options
- Departure logistics
- Ideas and contributions

All responses are automatically saved to a Google Sheet for easy coordination.

## ✨ Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- **Dynamic Questions** - Questions conditionally show/hide based on user responses
- **Progress Bar** - Visual feedback on form completion
- **Google Sheets Integration** - Responses automatically saved to a spreadsheet
- **Beautiful UI** - Dark theme with gradient accents and smooth animations
- **Accessibility** - Semantic HTML, proper error handling, keyboard navigation

## 🛠 Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with CSS variables, flexbox, and gradients
- **Vanilla JavaScript** - No dependencies, pure JS for interactivity
- **Google Apps Script** - Backend for saving data to Google Sheets
